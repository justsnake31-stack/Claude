          Точно удалить все результаты?

          Результаты сохраняются на этом телефоне до очистки. Фото после перезапуска приложения не показываются, остаются только названия и сроки. Проверяйте спорные позиции глазами: программа может ошибиться в цифрах, особенно на смятых или бликующих наклейках. Первый запуск требует интернета (загружается ~38 МБ), дальше обычное распознавание работает и без него. «Точный анализ» работает только с интернетом.

          ✨ Точный анализ — ключ Claude

          Фото этикеток отправляются в Claude (Anthropic) и читаются моделью, которая видит фото как человек. Нужен ваш ключ API: зайдите на console.anthropic.com → API Keys, пополните баланс и создайте ключ (начинается с sk-ant-).

          Ключ хранится только на этом телефоне. Стоимость — примерно $0,03–0,06 (≈3–6 ₽) за фото, списывается с баланса Anthropic.
